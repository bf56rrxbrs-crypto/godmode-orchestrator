# MultiPerspectiveSynthesizer

Analyze the problem from these distinct perspectives:

1. **Technical Expert** — feasibility, implementation details, constraints, best practices
2. **End-User / Practical** — usability, real-world friction, immediate value
3. **Strategic / Long-term** — second-order effects, scalability, opportunity cost, alignment with larger goals

For each perspective provide:
- Key insights
- Risks / downsides
- Opportunities / upsides

### Final Synthesis (MANDATORY)
Reconcile the perspectives into a single clear recommendation.
Explicitly identify the strongest conflicts between viewpoints and explain how you resolved them.
State your final recommendation with confidence level (High / Medium / Low).
List the conditions under which you would change this recommendation.
